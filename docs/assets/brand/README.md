# Brand assets

| File | Use |
| --- | --- |
| `hero-banner.png` | README hero (1600×460) |

| `logo.png` | Square mark / avatar (512×512) |

The visual system is **editorial brutalism / neo-Swiss print**: cream paper,
Noto Serif Display, IBM Plex Mono captions, fluorescent spot inks, registration
marks and a CAPTCHA sample in a dark red / navy / ochre riso disc. The captcha
value is `k7ap`. The wordmark and mark are original to KaptchaOCR.

Typefaces are **Noto Serif Display**, **IBM Plex Sans** and **IBM Plex Mono**
(SIL Open Font License); no font files are redistributed.
